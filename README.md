# ポケモン SV 育成クイズ

『ポケットモンスター スカーレット・バイオレット』の育成に関わる数字（**種族値・個体値・努力値・せいかく**）と、**ダメージの倍率・タイプ相性**を、ざっくりした説明とクイズで覚える静的 Web アプリです。
SV では、おうかんでの個体値の強化、ミントでの性格補正の変更、きのみやもちでの努力値のリセットが手軽にでき、エンディング後にはジャッジで個体値も確かめられます。それなのにゲームの中ではしくみの説明があまりないので、「どのくらい違うのか」を数字でつかむことを目的にしています。厳密なダメージ計算は扱いません。

HTML / CSS / JavaScript だけで動き、ホーム画面に追加（インストール）できます。

## 注意

- **個人が作成した非公式のファンアプリです。** 任天堂・株式会社ポケモン・ゲームフリーク・クリーチャーズ、その他の権利者様とは一切関係ありません。
- **数値は目安です。** ゲームの中のダメージ計算は途中で何度も切り捨てたり 4096 分率で計算したりしているので、このアプリの倍率は理解のための「ざっくり」の値です（能力の実数値の計算は正確な式を使っています）。
- **ネタバレ対策**：初回起動時と「設定」で、進み具合を 8 段階（序盤／本編／終盤／クリア後／碧の仮面／碧の仮面の終盤／藍の円盤／藍の円盤の終盤・番外編）から選べます。選んだ段階より先で出会うポケモン（伝説・パラドックス・追加コンテンツのポケモンなど）は、ずかん・クイズ（選択肢を含む）・説明の例・集計（平均やランキング）に出ません。本編の 4 段階は元ネタ推測図鑑と同じで、追加コンテンツは本編クリア後に遊ぶ前提で後ろに並べています。
- 対象は、パルデア図鑑の 400 種・本編で手に入る図鑑外の 2 種（ヌオー・ニャイキング）・追加コンテンツ「ゼロの秘宝」のキタカミ図鑑とブルーベリー図鑑のポケモン（パルデア図鑑と重なるものを除いて 263 種、合わせて 665 種）。

## 画面

- **まなぶ**：説明（下の「まなぶの内容」）。21 の章は最初は折りたたまれていて、上の目次ボタンを押すとその章が開いて移動する。「すべて開く／閉じる」もある
- **クイズ**：今日の練習数と連続日数、はじめての人向けのステップ（19 段階、押すとすぐ始まる）、難しさ、14 の分野
- **ダメ計**（ダメージ計算機）：攻める側（実数値・ランク・タイプ一致・もちもの・やけど）、技（威力・相性・天気・きゅうしょ）、受ける側（HP・防御の実数値・ランク・もちもの・壁）を動かすと、ダメージの幅（乱数 85〜100%）・HP の何%か・確定何発かが出る。ポケモンを選ぶと、努力値 0/252・せいかく補正から実数値を入れられる。「計算の流れ」で式の途中の値を、「くらべてみる」で相性やランク・もちものを変えたときの違いを表で見られる。例のボタン（こうげき 100・威力 50・つるぎのまい 2 回・タイプ一致 など）つき
- **種族値**：パルデア図鑑のポケモンの種族値ずかん。検索・タイプで絞り込み・能力ごとの並び替え・最終進化だけ。開くと能力のグラフ、とくせい（隠れ特性つき）、進化の系統ごとの合計、受けるときのタイプ相性、レベル 50 のすばやさ
- **記録**：連続日数・今日・これまで、2 週間の棒グラフ、分野ごとの正答率（押すとその分野を練習）、苦手な組み合わせ
- **設定**：ネタバレ範囲、テーマ（自動／スカーレット／バイオレット／オレンジ／グレープ／スター／カシオペア）、記録の消去、このアプリについて

### まなぶの内容

1. 強さを決める 3 つの数字（種族値・個体値・努力値）とせいかく、レベル 50 のざっくりした式
2. 能力の計算機：ポケモン・能力・個体値・努力値・せいかく・レベルを動かすと、実数値と「最低〜最高」の幅が分かる
3. 種族値：見分けのコツ（進化段階ごとの平均、600 族、伝説、素早いタイプ・遅いタイプ）、**御三家 3 系統の比較**（合計は同じで配分が違う）、**イーブイと 8 つの進化の比較**（8 種とも合計 525、130 と 110 の位置が違う）、データで見る傾向
4. 個体値：0〜31、すごいとっくん（ぎん／きんのおうかん・フリッジタウン・Lv50 以上）、ジャッジの言葉と個体値
5. 努力値：1 つ 252・合計 510、増やす（えいようドリンク＋ 10・ハネ＋ 1・パワー系＋ 8・もち＋ 10）、減らす（きのみ −10・まっさらもち）、アイテム名の一覧
6. せいかくとミント：25 種の表
7. ダメージの倍率：タイプ一致・きゅうしょ・テラスタル・ランク・いかく・やけど・天気・もちもの・とくせいの倍率表と、かけ算の例。ランクの倍率の帯
8. タイプ相性：言葉と倍率の対応、18×18 の相性表（押すと覚え方）、タイプを選ぶと弱点・耐性が出るしらべもの
9. 特殊な相性の技（フリーズドライ・フライングプレス・テラバースト・ウェザーボール・めざめるダンス・レイジングブル）、タイプのない攻撃（わるあがき・こんらんの自傷、いばるで自傷が痛い理由）、状態異常にならないタイプ、テラスタル
10. とくせい：ふつうの特性と隠れ特性・手に入れ方（テラレイド・タマゴ・とくせいパッチ／カプセル）、特別なとくせい（ケッキングの なまけ など）、相性を変えるとくせい
11. 対戦でよく見るもちもの

追加した章：

- **種族値ランキング**：合計・能力ごとに高い順／低い順の 15 匹（伝説を入れる・最終進化だけ を切り替え）
- **ランク・急所・命中**：ランクの倍率を動かして確かめる、急所ランク（1/24・1/8・1/2・必ず）、命中・回避ランク（4/3・5/3…）、ランクが消える・変わるとき
- **技の分類**：変化技・物理技・特殊技の違い（使う能力・影響を受けるもの）、タイプではなく技ごとに決まること、「ブースターならフレアドライブとふんえんのどっち？」の計算の例、タイプを選ぶと物理技・特殊技の一覧が出るしらべもの、計算が特別な技（サイコショック・ボディプレス・イカサマ・テラバースト）、特例として威力でダメージが決まらない技（ナイトヘッドなどの固定ダメージ・カウンターなど・一撃必殺・くさむすびなど威力が変わる技。`data-rules.js` の `SPECIAL_DMG`）
- **タイプ相性の計算の例**：「くさ・ほのお（スコヴィラン）に みず技」を 1 段ずつ。しらべものでも技のタイプを選ぶと内訳が出る
- **割合ダメージ**：ステルスロック（いわの相性ごとの割合と、いまの範囲のポケモンの例）、まきびし・どくびし・やけど・どく・もうどく・しおづけ・ゴツゴツメット・いのちのたま・回復など
- **対戦でよく使う変化技**（トリックルーム・ひっくりかえす・ちょうはつ など）と、**入れ替え・コピーの技**（もちもの・とくせい・ランク・能力の数値のどれを入れ替えるかで整理）
- **育成の例**：カイリュー・サーフゴー・ハバタクカミ・キョジオーン・ドドゲザン・ミミッキュ・ディンルー・オーガポンの、とくせい・せいかく・努力値・もちもの・テラスタイプ・技と、それぞれの理由（一例）
- **ダブルバトル**：全体技の 0.75 倍、てだすけ・デコレーション・このゆびとまれ・ねこだまし・ワイドガード など、味方の特性を使った全体技、技の範囲の一覧（味方にも当たる技／相手 2 体だけの技／味方を助ける技）
- **テラレイドバトル**：★ ごとの HP の倍率、何回で倒せるかの計算、バリア・能力変化の解除・追加行動・テラスタイプ・ひんしの時間ペナルティ・おうえん、HP を割合で削る技（いかりのまえば・カタストロフィ）や一撃必殺がボスに効かないこと、失敗すると報告されている技（ほろびのうた・トリック など。プレイヤーの検証による）
- **通信対戦のルール**：レベル 50 補正、見せ合い、同じポケモン・もちもの禁止、レギュレーションで伝説などが使えない時期がある

数字のうち、平均・範囲・「いちばん速いポケモン」などはデータから計算して表示しているので、データを更新すれば説明も変わります。

難しさ：

- **やさしい**：差がはっきりした比較。タイプ相性は「こうかばつぐん／ふつう／いまひとつ／こうかなし」の言葉で答える
- **ふつう**：タイプ相性は 0〜4 倍 の倍率で答える。種族値の比較は差が小さめ
- **むずかしい**：タイプを隠して技とポケモンの名前だけで答える。とくせい問題は、名前を伏せて「対戦でよく見るとくせい」（`POPULAR_ABILITIES`）を考える。すばやさ比べは種族値を隠し、トリックルームも出る

間違えた組み合わせ（「みず技 → くさ・ほのお」など）や知識問題は記録され、「間違えた問題を多めに出す」がオンなら多めに出題されます。キーボード：1〜9 で回答、Enter で次へ、Esc でやめる。

### 知識問題の書き方（`data-rules.js` の `KNOWLEDGE`）

```js
{ c: 'ev', l: 1, q: '1つの能力に入れられる努力値の上限は？', a: ['252', '255', '510', '100'],
  ex: '1つの能力は252まで（第6世代から）。', tag: '努力値の上限', sp: 0 }
```

`c` 分野（base / iv / ev / nature / dmg / item / ab / cat / chip / battle / raid）、`l` 難しさ（1〜3）、`a` の先頭が正解、`tag` は記録・苦手の表示名（同じ tag の問題はまとめて数える）、`sp` はネタバレ段階（省略時 0）。
